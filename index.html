    Demo script

    1. Point at the steady state: fast responses, no errors.
    2. On Fragile, click Kill cache. Requests pile up waiting, then errors spike.
    3. Click Reset, then switch to Resilient.
    4. Kill the cache again. The circuit breaker opens, traffic goes to the database, the steady state holds.
    5. Try Slow cache to show a quieter failure.
    1. Four honest nodes confirm one block per round.
    2. Crash one node. Blocks keep coming: f = 1 is tolerated.
    3. Crash a second node. Only 2 honest votes, no quorum, the chain stops.
    4. Reset, then make one node Malicious. Still 3 honest votes, still working.
    5. Split network. Each side has 2 nodes, so neither side can confirm.
